# Voice BBS UI primitives

Design-system implementation layer for `docs/design-system.md`.

- `DesignButton.vue` — action primitive; 44px target, keyboard focus, reduced-motion support.
- `DesignPanel.vue` — surface primitive using semantic surface/border tokens.
- `DesignSheet.vue` — responsive bottom-sheet/dialog primitive.
- `VoiceBubble.vue` — voice-domain primitive; category and playback/ownership states.

Domain-to-UI mapping is maintained in `docs/ontology-ui.yaml`.
