# UX設計 `?kids=1` — 10歳 (小4〜5) 向け

> 前提: `docs/ux.md` の大人版6軸は維持し、本書は kids 時の差分のみを定義する。
> 対象年齢: 10歳 (小学4〜5年)。ひらがな・カタカナOK、漢字はふりがながないと止まる。

## 1. ペルソナ

- 10歳、タブレットは学校で触ってる、スマホは親と共有もあり
- 長押し・スワイプはできるが、失敗すると投げる。成功体験が先に要る
- 音を出せない場所 (教室・電車) でも遊びたい

## 2. 原則 (大人版からの変更点のみ)

1. **読めない文字を出さない** — 漢字は全て `<ruby>` ふりがな。カタカナ外来語は避ける
2. **1画面1やくわり** — ロビー=選ぶ、部屋=きく・はなす、録音=はなす、を混ぜない
3. **2タップ完結** — 長押し260ms待機・スライドキャンセルは kids では廃止
4. **音なしで完結** — 全状態に文字+色+アニメ (再生中=ぷるぷる、録音中=赤く大きく)
5. **あんぜんが操作より上** — 通報・おやくそくは1タップで届く位置に

## 3. 画面フロー

```text
[おやくそく] (初回のみ)
  「ほんみょう・がっこう・ばしょ・でんわばんごうは いわないでね」
  [わかった! (おおきく)] → ロビーへ
      │
ロビー `/ ?kids=1`
  ┌ カテゴリ4つ (固定・ひらがな):
  │  きいてほしい / さがしてる / こまってる / じまんしたい
  │  ※ motetai は表示しない
  └ 部屋カード: タイトル(ふりがな) + 声のかず + カテゴリ色のふち
      │ タップで入る
      ▼
部屋 `?room=xxx&kids=1`
  ┌ 泡 = 80px以上、タップで きく/とまる (トグル表示必須)
  ├ 下中央に おおきなマイクボタン (64px以上)
  │   [おす] → 「はなしてね」(10秒カウント) → [おくる] → 泡が生まれる
  └ 各泡の右下に `こまったとき` (通報・非表示申請)
```

## 4. コンポーネント差分

| 現状 | kids=1 |
|---|---|
| `page.tsx` ダーク `slate-950` 白文字 | 空色 `#BFE9FF`→白、文字は濃紺 `#0F2A44`、コントラスト7:1以上 |
| `CategoryTabs.tsx` `text-sm` | `text-base font-bold`、選択中は太枠+下線つき |
| `BubbleField.tsx` 64px・タップ=再生/長押し=削除 | 80px+、タップ=きく/とまるのみ。削除メニューは出さない (本人削除は部屋の `せってい` に隔離) |
| `Recorder.tsx` 長押し帯 | 2タップ式 + 10秒自動ストップ + やりなおしボタン |
| 追加 `PromiseSheet.tsx` | 初回おやくそく + 録音前チェック (電話番号・学校名っぽい文字をはじく) |

### 4.1 kidsラベルマップ (実装済み: `CategoryTabs.tsx`)

```ts
const KIDS_LABELS: Record<string, string> = {
  want: "きいてほしい",
  search: "さがしてる",
  trouble: "こまってる",
  motetai: "じまんしたい", // 表示時は除外し、新規作成時の選択肢にも出さない
};
```

- kids 時は `motetai` を一覧・作成選択肢の両方から除外する
- `すべて` → `ぜんぶ` に置換する
- ボタン最小 56px (`min-h-[56px] min-w-[56px]`)、文字 `text-base font-bold`

## 5. 文言ルール

- 漢字使用は小4配当 (800字) まで + 全てふりがな
- カタカナは `スタート→はじめる` `キャンセル→やめる` に置換
- 否定は理由つき: `✕ ダメ` → `◯ ほんみょうは いわないでね`

## 6. kids採点軸 (既存6軸 + 2軸追加、計40点)

| 追加軸 | 5点 | 3点 | 1点 |
|---|---|---|---|
| 7 **よめる** | 全漢字にふりがな、1文30字以内 | ほぼ読めるが一部詰まる | 大人の文のまま |
| 8 **あんぜん** | おやくそく→通報→削除依頼が各1タップ | 通報はあるが遠い | 通報導線なし・自動再生あり |

既存6軸の kids時重み変更: 軸1録音 ×2、軸6安心 ×2 で採点する。

## 7. 受入条件

- [ ] 10歳が初見で録音→再生まで3タップ以内で到達
- [ ] 音OFFでも録音・再生・通報が完結
- [ ] `motetai` が kids表示に一切出ない
- [ ] 全タップ領域 56px以上 (泡は80px以上)
- [ ] Lighthouse a11y 90+、コントラストエラー0
