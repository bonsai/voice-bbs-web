# FE Issue Map

Backend is treated as complete for this track. These issues are frontend refinement only.

## Sequence

`#4 FE Design System application → #2 waveform integration → #6 visual polish → #5 verification`

## Out of scope

- Cloudflare / D1 / R2 backend implementation
- API contract changes
- authentication / authorization backend
- database schema changes

## Definition of Done

The frontend is considered polished when the product reads as one coherent Voice BBS experience across lobby, room, recorder, player, and sheet; all states follow the Design System; mobile/desktop and reduced-motion behavior are verified; and test/typecheck/build are green.
