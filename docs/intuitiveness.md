# Voice BBS — 直感性の設計原論

> 2026-09-05
> 基準: ジェームズ・ギブソン「アフォーダンス」× 5界 (武蔵野美大)
> 問い: **「ユーザーは、何を「できる」ことを「知覚」できるか」**

---

## 1. 直感の定義

> 「直感的」とは、「説明なしに行動できる」状態

| 直感的でない | 直感的である |
|---|---|
| 泡の長押し → 録音 | 丸いものは押せる |
| 波線パターン → 音声データ | 波形 → 声 |
| 画面のどこで離しても録音終了 | 離す → 投稿 (自然な動作) |

---

## 2. 5界のフレームワーク

ギブソンのアフォーダンス理論を5界で分解する。

### 2-1. 知覚界 — 何を「見て取れる」か

| 要素 | 知覚できているか | 問題 |
|---|---|---|
| 泡の丸み | ✅ | 丸い = 押せる (生物学的本能) |
| 泡の陰影 | ✅ | 浮いている = 触れる可能性 |
| 泡の浮遊 | ✅ | 動いている = 生きている |
| 長押しの前兆 | ❌ | 260ms無応答 = 「動かない」 |
| 波形の意味 | ⚠️ | PNG画像 = 音と繋がらない |
| 離す=投稿 | ❌ | 離すという行為自体に意味がない |

**知覚界の核心: アフォーダンスとは「手が触れる前に行為の可能性が見えること」**

- 丸い = 押せる (✅ 生物学的に確実)
- 影がある = 浮いている = 触れる (✅)
- 波形 = 音 (❌ 抽象的すぎ)
- 長押し = 録音 (❌ 手がかりなし)

### 2-2. 行動界 — 何を「できる」か

| 行動 | アフォーダンス | 直感的か |
|---|---|---|
| 泡をタップ | 丸形 + 浮遊 | ✅ 自然な押下 |
| 泡を長押し | 長押しの手がかりなし | ❌ 直感的でない |
| 下帯を長押し | 丸形 + 浮遊 | ⚠️ ボタンらしいが「何」か不明 |
| 指を離す | 離す動作自体に意味 | ❌ 「離す=投稿」とは繋げない |

**行動界の核心: 行動は「手がかり」から生まれる**

- 丸いものは押す (✅)
- 長押しで録音 (❌ 手がかりが「押せる」だけ)
- 離すと投稿 (❌ 離す行為にアフォーダンスなし)

### 2-3. 意味界 — それが「何を意味」するか

| 要素 | 意味 | 直感的か |
|---|---|---|
| 泡 = 声 | 抽象的変換 | ❌ 直感的ではない |
| 波形 = 音声データ | 技術的表現 | ❌ 直感的ではない |
| 長押し = 録音 | 慣習的 | ⚠️ 次第 |
| 離す = 投稿 | 慣習的 | ❌ 離す行為には意味がない |

**意味界の核心: 「泡 = 声」は直感的でない。発見可能にするには**

- 泡を押すと音が鳴る → 発見
- 音 → 泡は声だと理解

**「意味」は事前に与えるものではなく、行動の「結果」から生まれる**

### 2-4. 認知界 — ユーザーは「どう理解」しているか

| 段階 | 認知 | 直感的か |
|---|---|---|
| 初期 | 「泡がたくさんある」 | ✅ |
| 泡タップ | 「泡が鳴った」 | ✅ |
| 泡 = 声 | 発見 → 理解 | ⚠️ 時間がかかる |
| 長押し | 「何かが起きる？」 | ❌ わからない |
| 離す | 「投稿された？」 | ❌ 原因と結果が不明 |

**認知界の核心: ユーザーは「結果」を見て「意味」を構築する**

### 2-5. 表現界 — どんな「雰囲気」を呼ぶか

| 要素 | 表現 | 効果 |
|---|---|---|
| 泡の浮遊 | 空間情緒 | ✅ 没入感 |
| 暗い背景 | 静寂感 | ✅ |
| 波形 | データの可視化 | ❌ 情緒を削ぐ |
| 260msの無応答 | 遅延 | ❌ 不安 |
| 離すの表現 | なし | ❌ 何が起こったか不明 |

## 3. 直感性の診断まとめ

### 3-1. 泡の直感性

| 階層 | 直感的か | 理由 |
|---|---|---|
| 泡の形状 (丸) | ✅ | 丸い = 押せる (生物学的本能) |
| 泡の陰影 | ✅ | 浮いている = 触れる |
| 泡の浮遊 | ✅ | 動いている = 生きている |
| 泡を押して音 | ⚠️ | 結果は良いが、「押すと音が出る」とは直感的に分からない |

### 3-2. 録音の直感性

| 階層 | 直感的か | 理由 |
|---|---|---|
| 泡の長押し | ❌ | 長押しの手がかりなし |
| 下帯の長押し | ❌ | 長押しの手がかりなし |
| 離す → 投稿 | ❌ | 離す行為に意味がない |
| 波形表示 | ⚠️ | 「録音中」は分かるが「何の波形」か不明 |

### 3-3. アフォーダンスの欠如

**アフォーダンスとは「手が触れる前に、その物体が何を提供しているか」が見えること**

| 要素 | アフォーダンス | 欠如しているもの |
|---|---|---|
| 泡 | 「押す」 | ✅ |
| 波形 | 「音」 | ❌ (画像にしか見えない) |
| 長押し | 「録音」 | ❌ (手がかりなし) |
| 離す | 「投稿」 | ❌ (行為に意味なし) |

---

## 4. 直感的にするには

### 4-1. 泡の改善

```
[泡の形状]  丸い → 押せる ✅
[泡の動き]  浮遊 → 触れる ✅
[泡の応答]  押すと膨らむ → 「押せた」 ❌ → 追加
[泡の音]    鳴る → 音が出た ✅
```

### 4-2. 録音の改善

```
[下帯の形状]  丸い → 押せる ✅
[押下応答]    少し膨らむ → 「押せた」 ✅ 追加
[波形表示]    動き出す → 「録音中」 ✅ 追加
[離す]        波形が吸い込まれる → 「投稿」 ✅ 追加
```

### 4-3. 5界のバランス改善

| 界 | 改善前 | 改善後 |
|---|---|---|
| 知覚界 | 泡の浮遊は良いが、波形の意味が不明 | 膨らみ + 波形で「押せる」ことを示す |
| 行動界 | 長押し=録音 (手がかりなし) | 膨らむ → 長押し → 波形 (順次応答) |
| 意味界 | 泡=声 (抽象的) | 膨らみ=押せた、波形=声 (結果から理解) |
| 認知界 | 泡を押して再生 (時間がかかる) | 膨らみ→音、膨らみ→波形→録音 (段階的理解) |
| 表現界 | 泡の浮遊感 (良い) | 泡の浮遊感 + 膨らみ + 波形 (表現の増加) |

## 5. 結論

**「直感的」とは「説明なしに行動できる」こと**

| 要件 | 実装 | 直感的か |
|---|---|---|
| 泡が押せる | 丸形 + 陰影 | ✅ |
| 泡を押すと音 | タップ → 再生 | ⚠️ 結果は良いが事前手がかりなし |
| 長押しで録音 | 長押し → 録音 | ❌ 手がかりなし |
| 離して投稿 | 離す → 投稿 | ❌ 行為に意味なし |

**解決策: アフォーダンスを「押す → 応答 → 投稿」に増やす**

1. **押す** → 泡/ボタンが少し膨らむ (scale 1.05)
2. **応答** → 波形が動き出す (録音中表示)
3. **投稿** → 波形が吸い込まれる (投稿アニメーション)

これにより、ユーザーは「何ができるか」を「見えて」、行動し、結果から「意味」を理解できる。
