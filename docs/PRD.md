# Voice BBS Web — PRD (Product Requirements Document)

> 状態: 公開アルファ(基本機能デプロイ済み) / 更新: 2026-09-03
> 設計: `docs/spec.md` / 実装実態: `docs/STACK.md` / 課題・機能要求: `issues/`

## 1. 概要 (One-liner)

**匿名・認証不要の音声掲示板。** 録音した声をシャボン玉にのせ、ふわふわ浮かぶスレッドとして投稿・再生できる。旧 voice_bbs (Elixir) の再構築版。

## 2. 背景・課題

- テキスト掲示板は匿名でも「文字に残る」重さがあり、気軽な声の投稿手段が少ない。
- 音声は即時的・感情的で、匿名性と組み合わせると軽いノリで参加しやすい。
- Cloudflare 無料枠のみで運用し、サーバーコストゼロを維持する。

## 3. ターゲット・ユーザーストーリー

- 主ユーザー: 気軽に声を残したい匿名ユーザー(コミュニティ内・知人同士の雑談利用を想定)
- ストーリー例:
  1. 「こんなのほしい」カテゴリに、喋った要望を吹き込んで投稿する。
  2. 帰宅後、浮かんでいるシャボン玉をタップして昨日の声を聞く。
  3. 自分の投稿(device_id 基準)は後から削除できる。

## 4. スコープ

### MVP(実装・デプロイ済み 2026-09-03)
| 機能 | 内容 | 制約 |
|---|---|---|
| 匿名録音投稿 | ブラウザ録音 → 無音トリム → 投稿 | 認証なし、device_id で識別 |
| シャボン玉 UI | スレッドを浮遊バブルで表示、カテゴリ別閲覧 | latest音声がバブル画像 |
| スレッド/投稿 API | 作成・一覧・削除・検索 | レート制限: device_id/日4件 |
| 自動連続再生 | スレッド内投稿を順に再生 | Web Audio API |
| 音声圧縮 | WAV → PNG バイト埋め込みでR2に保存 | 30秒/投稿上限 |
| 再生配信 | Pages Function 経由の同一オリジン配信 | r2.dev CORS 不可の回避 |

### P1(未実装 — `issues/`)
- TTS seed(Web Speech API サンプル投稿)
- PWA(manifest / service worker / offline)
- 投稿者本人削除(device_id ベース)→ 一部 API 実装済み・UI 未接続
- 古い投稿の自動クリーンアップ
- 接続状態オーバーレイ
- ランディングのマイクチェック

### 非スコープ(現時点)
- ユーザー登録・ログイン・プロフィール
- モデレーション UI / 管理者画面
- モバイルネイティブアプリ

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| コスト | Cloudflare 無料枠のみ(Pages / D1 / R2)。固定費ゼロ |
| 匿名性 | 個人情報・メール不要。識別は device_id(localStorage)のみ |
| 健全性 | レート制限で荒らしを軽減(4件/日/端末)。音声はR2に公開保存 |
| プライバシー | 録音はユーザー操作時のみ。マイク使用は明示 |
| 性能 | 録音→投稿が体感数秒。音声はクライアント処理でサーバー負荷なし |
| 可用性 | エッジ配信(static + Functions)。DBはD1 |

## 6. 成功指標(仮)

- 投稿数/日、投稿あたりの再生数
- 録音中断率(無音判定・エラーで投稿に至らない割合)
- 無料枠内で安定稼働していること(コスト指標)

## 7. 制約・既知の罠

- `docs/STACK.md` §5 参照: r2.dev CORS 不可、npm peer conflict、レート制限の設計等
- 音声の実データ保存形式(PNG埋め込み)は独自仕様 → 互換性維持が最優先
