# Voice BBS Web — PRD (Product Requirements Document)

> 状態: v2(2026-09-03) — **製品モデル変更: スレッド→部屋(room)、シャボン玉=声・触ると喋る**
> 本ドキュメントは「何を作るか」の要求定義。**「どう作るか」は `docs/spec.md`**(UX詳細・設計)、実装・運用実態は `docs/STACK.md` / `docs/deploy.md`。

## 1. 概要 (One-liner)

**匿名・認証不要の音声掲示板。** 声は泡となり、テーマごとの**部屋(room)**の中を漂う。**泡に触れるとその声が話す**。Cloudflare 無料枠のみで運用。

## 2. 背景・課題

- テキスト掲示板は「文字に残る」重さがあり、気軽な声の投稿手段が少ない。
- 音声は即時的・感情的。匿名 + 声なら軽いノリで参加しやすい。
- 旧 voice_bbs (Elixir) の再構築版。Cloudflare のみでサーバーコストゼロを維持。

## 3. ターゲット・ユーザーストーリー

- 主ユーザー: 気軽に声を残したい匿名ユーザー(コミュニティ内・知人同士の雑談)
- ストーリー:
  1. 「こんなのほしい」カテゴリの部屋に入り、欲しいものを吹き込む → 泡が生まれて部屋に浮かぶ。
  2. 帰宅後、部屋の泡をぽんぽん触って、昨日の声をその場で聞く。
  3. 自分の声(この端末の泡)は後から消せる。

## 4. 製品スコープ

### コア体験(設計 v2 確定 — 実装は一部 旧モデルのまま)
| 機能 | 要求 |
|---|---|
| 部屋 (room) | カテゴリ内のテーマの場。タイトル + 声の数。直接リンク可(`?room=`) |
| 声の泡 (voice bubble) | 1 録音 = 1 泡。長さでサイズ変化。room 内を漂う |
| **触ると喋る** | 泡タップでその声が即再生(遷移なし)。別の泡で割り込み可 |
| 録音 | 長押し録音 → 泡が生まれる。無音/短すぎは却下。30 秒上限 |
| アンビエント | 部屋の声が「ちょっとずつ聞こえてくる」(任意 ON。位置で音量変調) |
| 本人削除 | 自分の device_id の泡のみ削除可能(UI は P1) |
| **操作原則** | タッチ専用 UI。**文脈で操作が変わる**: ロビーの空き=部屋を作る / 部屋内の空き=吹き込む / 泡=聞く。部屋名も声で入力(音声認識) |
| レート制限 | 端末あたり本日 4 件(健全性) |

### P1(未実装 — `docs/issue.md`)
- 部屋タイトルの音声入力 / TTS サンプル seed
- PWA(offline)
- アンビエント詳細、泡の長押し削除 UI、接続状態オーバーレイ、ランディングのマイクチェック

### 非スコープ(現時点)
- ユーザー登録・ログイン・プロフィール
- モデレーション UI / 管理者画面
- モバイルネイティブアプリ

## 5. 成功指標(仮)

- 投稿数/日、泡あたりの再生数(触られた回数)
- 録音中断率(投稿に至らなかった割合)
- 無料枠内で安定稼働(コスト指標)

## 6. 制約(要求レベル)

- **匿名**: 個人情報・メール不要。識別は端末の device_id のみ
- **健全性**: レート制限 4 件/日/端末。本人以外の削除不可
- **プライバシー**: マイク使用はユーザー操作時のみ。録音開始は明示
- **コスト**: Cloudflare 無料枠のみ。固定費ゼロ
